🆘 HELP:

Q: Script says "No media files found"
A: Make sure files are in ~/Downloads/happy-customers/ or ~/Desktop/happy-customers/

Q: "ffmpeg not found"
A: brew install ffmpeg (macOS) or apt-get install ffmpeg (Linux)

Q: Images don't show on website
A: Check file names are lowercase, use hyphens not spaces, clear browser cache (Cmd+Shift+R)

Q: Video doesn't play
A: Ensure MP4 codec is H.264, check poster image exists

For full troubleshooting → see CUSTOMER_MEDIA_INTEGRATION_GUIDE.md
